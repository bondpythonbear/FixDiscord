>
> Добавьте каталог с запретом в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Если вы уверенно понимаете настройки исключений, лучше добавить нужную папку в исключения; при недостаточном понимании этих параметров рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите Secure DNS (Безопасный DNS)
    * В Chrome откройте пункт "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно активировать непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic следует включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Перейдите на [страницу последнего релиза](https://github.com/bondpythonbear/zapret-discord-youtube/releases/latest) и скачайте архив zip/rar

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие — пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  В скобках отображается текущий статус — включено или выключено.
  - **`IPSet Filter`** — переключить обход для сервисов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается выбранное состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяются IP, входящие в список
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность после внезапного сбоя
  - **`Run Tests`** — открыть инструмент тестирования стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, отвечающий за обход. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/bondpythonbear/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте полный текст из открывшегося блокнота
  - С помощью текстового редактора, запущенного от имени администратора, откройте файл `hosts` в появившемся каталоге
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/bondpythonbear/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно остаются рабочими навсегда.**
> Обнаружение может привести к тому, что ранее работавшая стратегия со временем перестанет помогать.
> Здесь доступно много разных стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что нужный адрес присутствует в доменных или IP-списках

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/bondpythonbear/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- В `service.bat` выберите `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите каталог запрета
- Загрузите свежую версию [со страницы релизов](https://github.com/bondpythonbear/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если в правом нижнем углу есть пункт разблокировки, отметьте его, нажмите применить и ОК
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- По очереди проверьте разные скрипты `general`. Если интернет-ресурсы недоступны, закройте программу через значок замка на панели задач и запустите следующую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы в командной строке Windows, открыв её через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Если прежняя стратегия больше не помогает, протестируйте все остальные
- См. также [#251](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и убедитесь, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях
- Дополнительное обсуждение: [#252](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/bondpythonbear/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете

### Не работают игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Начните с наиболее универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте тему в разделе [Discussions](https://github.com/bondpythonbear/zapret-discord-youtube/discussions), а не в issues, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/bondpythonbear/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже находится в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
